<task type="auto">
  <name>Task 2: Implement InvertedIndex with boolean query intersection</name>
  <files>src/services/search/InvertedIndex.js</files>
  <action>
    Create src/services/search/InvertedIndex.js:
    - tokenize(text): splits text into alphanumeric tokens, normalizes lowercase, strips punctuation while retaining hyphenated tech tags.
    - InvertedIndex class:
      - Internal index table: Map of token -> Set of document IDs.
      - Document store: Map of documentId -> document entity.
      - Integrates PrefixTrie for prefix autocomplete on vocabulary tokens.
      - addDocument(doc): indexes title, description, tags, developer name, and category.
      - query(queryString, options):
        - Multi-term evaluation: checks term matches, performs set intersection (AND) and union (OR).
        - Relevance scoring based on title match weight (x3), tag match weight (x2), description match (x1), and popularity.
        - Returns ranked list of document entities with match score and matched terms.
  </action>
  <verify>Check that InvertedIndex exports addDocument and query methods</verify>
  <acceptance_criteria>
    - src/services/search/InvertedIndex.js performs tokenization, index mapping, and boolean query ranking.
  </acceptance_criteria>
  <done>InvertedIndex engine implemented.</done>
</task>
